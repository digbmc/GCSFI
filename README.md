This site is rendered using Quarto. The site renders from the docs folder, which is created through Quarto. 
Changes to the layout, aesthetics, or elements of the site require downloading a local copy of the files, and re-uploading them as a new branch.
Changes to the actual text content of the site can be made in each corresponding .qmd file, but must be run through Quarto locally to be appear in the docs folder and website. 

The files correspond to the following elements of the site: 
- about.qmd is the about page.
- dataset.qmd is the page that contains the post45 data viewer itself. 
- header.html is the yellow banner containing the project name.
- index.qmd is the homepage of the site
- contact.qmd is the contact form that will be built into the site.
